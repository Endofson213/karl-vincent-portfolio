# Karl Vincent Paclar portfolio

Dark, responsive Next.js portfolio for Karl Vincent Paclar.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

The project is intentionally self-contained: project visuals are stored in `public/`, and the portfolio copy is authored in `app/page.tsx` so it can be updated quickly.
